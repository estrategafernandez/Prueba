# Notas para Claude

## Casagencia: mensajes a clientes

- **El nombre del cliente, bien escrito.** Cuando Claude mande a mano un mensaje
  o una plantilla a un cliente (por ejemplo el `{{1}}` de la plantilla abierta),
  el nombre va con mayúsculas y con el apellido separado: "Juanjo Villagran",
  no "juanjovillagran" como llega a veces del portal. Si no se sabe dónde
  partirlo, solo el nombre de pila ("Juanjo"). No añadir tildes que no se sepan
  seguras. (Lo pidió Jaime el 6-11-2026.)
